Google Calendar API

Подключите свой Google аккаунт для работы с календарём

📋 Инструкция:

  1. 1. Перейдите в Google Cloud Console
  2. 2. Создайте новый проект или выберите существующий
  3. 3. Включите Google Calendar API
  4. 4. Создайте OAuth 2.0 Client ID (тип: Desktop app)
  5. 5. Добавьте redirect URI: http://localhost:8080/auth/callback
  6. 6. Скачайте credentials.json и положите в корень проекта
