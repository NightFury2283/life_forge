# Тестирование

```powershell
go test ./...
go vet ./...
go test -race ./...
go test ./internal/app -run TestIntegration -v
node --test tests/frontend.test.cjs
```

Модульные тесты проверяют авторизацию/JWT, профили, характеристики и награды, шифрование Google-токенов, календарь, чат, разбор дат и HTTP-ошибки. Используются стандартные testing, httptest, табличные тесты и подмена зависимостей через интерфейсы.

HTTP-интеграционные тесты собирают реальные роутер, middleware и сервисы с хранилищем в памяти. Проверяются вход/выход, OAuth state, изоляция пользователей и создание события только после подтверждения.

Регрессии: четверг не становится понедельником; московское время не зависит от зоны устройства; повторное завершение задачи не даёт награду.

Автотестам не нужны Docker, внешние аккаунты или ключи. Они не заменяют проверку миграций на PostgreSQL и реального обмена с Google/GigaChat. Не создавайте события в личном календаре ради проверки без разрешения.
